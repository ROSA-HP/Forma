# Forma – Athletic OS

Forma is a local-first, mobile-first athletic workout tracking operating system built with React, Vite, Tailwind CSS, and IndexedDB. Tailored for multidisciplinary athletes across weightlifting, calisthenics, martial arts, and cardio.

## Key Features

- **Local-First Architecture**: Powered by IndexedDB (`idb`) with 100% offline capability, zero telemetry, and client-side encryption readiness.
- **Crash-Proof Engine**: Live rest timers, round timers, and active workout tracking with timestamp-derived delta calculation and screen wake-lock.
- **Hypertrophy Radar**: 6-region muscular recovery balance hexagon radar (Chest, Delts, Arms, Back, Legs, Core).
- **Personal Record Tracking**: Real-time 1RM (Epley formula), heaviest weight, and volume PR detection with celebratory fanfares.
- **Bilingual & Accessible**: Full English and Arabic (RTL) support with instant locale switching.

## Building an Android APK with Capacitor

### Prerequisites

- **JDK 17 – 24** (this project's Gradle 8.14.3 / AGP 8.13 cannot run on JDK 25; Android Studio's bundled JBR 25 is too new). Temurin 21 works.
- **Android SDK** with build-tools and a platform (AGP downloads missing components automatically once SDK licenses are accepted).
- `JAVA_HOME` and `ANDROID_HOME` pointing at those installs.

### Build

```bash
# 1. Install dependencies and build web assets
npm install
npm run build

# 2. Add Capacitor Android platform (only needed once)
npx cap add android

# 3. Synchronize assets and plugins after every web build
npx cap sync android

# 4. Build a debug APK
cd android && ./gradlew assembleDebug
```

The resulting debug APK is generated at:
`android/app/build/outputs/apk/debug/app-debug.apk`

Install it on a device with `adb install -r app-debug.apk`, or open the project in Android Studio with `npx cap open android`. The `android/` folder is generated by Capacitor and can be regenerated at any time; the web source of truth stays in `src/`.
